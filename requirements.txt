# ---------- 向量库 ----------
# 选 1.0.x 而不是 0.5.x 的原因（这是一个真实的平台兼容坑）：
#
#   chromadb 0.5.x 硬依赖 `chroma-hnswlib==0.7.6`，
#   而 0.7.6 这个版本**没有发布 Windows + Python 3.12 的预编译轮子**
#   （只有 macOS / Linux / cp310 / cp311 的 win 轮子）。
#   于是 pip 会退化成"从源码编译 hnswlib"，而编译需要完整 MSVC C++ 工具链，
#   实测报错：
#       fatal error C1083: 无法打开包括文件: "float.h": No such file or directory
#   而且 pip 的失败信息被埋在几百行输出里，表现为"命令卡住不动"，
#   极难定位（详见第 1 章文档的完整排查记录）。
#
#   chromadb 1.0 起把索引实现换成自带方案，运行时**不再依赖 chroma-hnswlib**
#   （只在 dev extra 里保留），因此 Windows + Python 3.12 可正常安装。
chromadb==1.0.15
