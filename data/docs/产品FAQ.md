# 星云数据平台 产品常见问题（FAQ）

## 一、产品定位

星云数据平台（Nebula Data Platform）是一站式数据集成与分析平台，
面向中大型企业提供数据接入、清洗、建模、可视化与智能问答能力。

## 二、版本与定价

星云平台提供四个版本：

| 版本 | 价格 | 适用规模 | 核心差异 |
|---|---|---|---|
| 社区版 | 免费 | 个人开发者 | 单机部署，最多 5 个数据源 |
| 标准版 | 每年 29800 元 | 10 人以下团队 | 最多 20 个数据源，含工单支持 |
| 专业版 | 每年 88000 元 | 50 人以下团队 | 不限数据源，含智能问答模块 |
| 企业版 | 面议 | 大型企业 | 私有化部署，专属客户成功经理 |

所有付费版本均包含一年的免费升级与技术支持。
续费价格为原价的 90%。

## 三、试用政策

新用户可申请 30 天全功能试用，无需绑定支付方式。
试用期结束后数据保留 60 天，逾期未付费将自动清理。
同一企业主体在 12 个月内只可申请一次试用。

## 四、部署方式

1. **SaaS 模式**：直接使用云端服务，开箱即用，数据存储在阿里云华东 2 区。
2. **私有化部署**：部署在客户自有服务器或专有云，支持信创环境。
   最低配置要求：8 核 CPU、32GB 内存、500GB SSD。
   推荐配置：16 核 CPU、64GB 内存、1TB SSD。
3. **混合模式**：核心数据留在本地，仅将聚合指标同步至云端看板。

私有化部署由实施团队上门交付，标准实施周期为 15 个工作日。

## 五、数据接入能力

平台内置 40 余种数据源连接器，覆盖：

- 关系型数据库：MySQL、PostgreSQL、Oracle、SQL Server、达梦、人大金仓
- 大数据组件：Hive、HBase、ClickHouse、Doris、StarRocks
- 消息队列：Kafka、RabbitMQ、Pulsar
- 对象存储：S3、OSS、COS、MinIO
- 业务系统：钉钉、企业微信、飞书、Salesforce
- 文件：CSV、Excel、JSON、Parquet、XML

单表增量同步的最高吞吐为每分钟 120 万行。

## 六、智能问答模块

专业版及以上提供基于 RAG 架构的智能问答：

- 支持上传企业私有文档（PDF / Word / 表格），构建专属知识库；
- 回答**附带引用溯源**，可点击查看原文出处；
- 支持多轮追问，上下文记忆默认保留 10 轮；
- 知识库更新为增量索引，单文档入库耗时通常在 5 秒以内。

## 七、安全与合规

平台已通过 ISO 27001 信息安全管理体系认证与等保三级测评。
支持数据传输 TLS 1.3 加密、静态数据 AES-256 加密。
支持细粒度权限控制，最小可控制到行级与列级。
审计日志保留 180 天，可导出至客户自有 SIEM 系统。

## 八、服务等级协议（SLA）

SaaS 模式承诺月度可用性 99.9%，未达标的按当月费用的 10% 逐档赔偿，
最高赔偿不超过当月费用的 100%。
工单响应时间：严重故障 30 分钟内响应，一般问题 4 小时内响应。

## 九、常见技术问题

**Q：支持多少并发查询？**
A：SaaS 标准版支持 50 并发，专业版 200 并发，企业版可按需扩容。

**Q：数据保留多久？**
A：SaaS 模式原始数据保留 3 年，聚合指标保留 5 年。私有化部署由客户自行决定。

**Q：是否支持国产数据库？**
A：支持达梦、人大金仓、GaussDB、OceanBase 等主流信创数据库。

## 十、API 与开发者能力

平台提供完整的 REST API 与 Python / Java SDK。

- REST API 采用标准 OpenAPI 3.0 规范，可在控制台下载 SDK。
- 免费版 API 调用配额为每日 1000 次；专业版为每日 10 万次；企业版不限。
- 单次 API 请求最大返回 10000 行数据。
- API 限流策略：默认每租户每秒 100 次请求，超出返回 429 状态码。

Python SDK 支持 `pip install nebula-sdk` 安装，兼容 Python 3.9 及以上版本。

## 十一、可视化与报表

平台内置 20 余种图表类型，包括折线图、柱状图、桑基图、热力图与地图。
看板支持拖拽式编辑，支持定时刷新（最小刷新间隔 1 分钟）。
报表可导出为 PDF、Excel 与 PNG，支持配置邮件定时推送。

单个看板最多支持 50 个图表组件，单图表最多展示 10 万条数据点。

## 十二、数据治理能力

- **数据血缘**：自动解析 SQL 与任务依赖，生成字段级血缘图谱，追溯深度默认 10 层。
- **数据质量**：支持空值率、唯一性、值域、正则表达式等 12 类校验规则。
  质量任务默认每天凌晨 2 点执行，异常结果通过钉钉与企业微信推送。
- **指标管理**：支持指标口径统一管理，指标变更需经数据治理委员会评审。

## 十三、常见部署问题

**Q：私有化部署支持容器化吗？**
A：支持。提供完整的 Helm Chart，可部署在客户自有的 Kubernetes 集群上。
最小集群规格为 3 个 8 核 32GB 节点。

**Q：升级会不会中断服务？**
A：小版本升级采用滚动更新，服务不中断；大版本升级需要 30 分钟左右的停机窗口，
会提前 7 个工作日通知客户。

**Q：数据能否迁移到其他平台？**
A：可以。平台所有数据均支持标准 SQL 导出，元数据可通过 OpenAPI 全量拉取，
不存在厂商锁定。

## 十四、客户支持

- **服务时间**：付费客户 7×24 小时工单支持，工作日 9:00-18:00 提供电话支持。
- **专属客户成功经理**：企业版客户配备一名专属客户成功经理，每季度提供一次业务复盘。
- **培训服务**：提供管理员培训（2 天）与开发者培训（3 天），企业版客户免费，
  其他版本按每人每天 2000 元收费。
- **知识库**：在线文档中心收录 800 余篇使用指南与最佳实践，
  并维护一个活跃的开发者社区论坛。
