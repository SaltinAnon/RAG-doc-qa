# 01 · 快速开始

> 目标：**15 分钟内**从零跑起来，浏览器里能提问并看到引用。

---

## 0. 前置检查

```bash
python --version
# 需要 3.11 或 3.12
# ❌ 不要用 3.13：chromadb 等依赖的预编译 wheel 覆盖不全，装依赖会现场编译
```

如果你的默认 `python` 是 3.13，用完整路径指定 3.12：

```bash
# Windows 示例
D:\Python\python.exe -V
```

---

## 1. 安装（三种方式选一）

### 方式 A：标准安装（推荐）

```bash
cd F:/WorkSpace/Newstart

# 1) 创建虚拟环境
python -m venv .venv

# 2) 升级 pip（老版本 pip 解析依赖容易出错）
.venv\Scripts\python.exe -m pip install -U pip       # Windows
# .venv/bin/python -m pip install -U pip             # macOS / Linux

# 3) 安装依赖（国内加镜像，速度差 10 倍以上）
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

> ⏱️ 首次安装约 3~8 分钟（chromadb、streamlit 依赖较多）。
> 如果卡在 `Installing build dependencies` 很久，是在编译某个包，耐心等，
> 或者换清华源 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

### 方式 B：用 Makefile（有 make 的环境）

```bash
make install     # 自动建 venv + 装依赖
make run-api     # 启动后端
make run-ui      # 启动前端
```

### 方式 C：Docker（跳过本地 Python 环境）

```bash
cd docker
docker compose up --build
```

## 3. 入库

```bash
# 先预演一遍（不写库、不调 Embedding，用来看切分质量）
.venv\Scripts\python.exe scripts/ingest_cli.py --dir data/docs --dry-run
```

输出示例：


## 4. 启动服务

**开两个终端。**

终端 1 —— 后端：

```bash
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000 --reload
```

## 5. 试用

1. 左下角确认「✅ 后端已连接」，「知识库片段」显示 85

## 6. 接入真正的 LLM（强烈建议）

```bash
copy .env.example .env          # Windows
# cp .env.example .env          # macOS / Linux
```

编辑 `.env`，把这段：

```ini
LLM_PROVIDER=offline
LLM_MODEL=gpt-4o-mini
LLM_API_KEY=
```

改成（以 DeepSeek 为例，性价比高、中文好）：

```ini
LLM_PROVIDER=deepseek
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-你申请的key
EMBEDDING_PROVIDER=openai
EMBEDDING_MODEL=text-embedding-3-small
```

> ⚠️ **换了 Embedding 模型必须重建向量库**：不同模型的向量维度不同，
> 同一个集合里不能混用。执行：
> ```bash
> .venv\Scripts\python.exe scripts/ingest_cli.py --dir data/docs --reset
> ```
> 否则会报维度不匹配的错误（报错信息里会直接告诉你这么做）。

重启后端，顶部黄条消失，答案就是真正由大模型生成的了。

## 8. 常见启动问题

| 现象 | 原因与解决 |
|---|---|
| `ModuleNotFoundError: No module named 'app'` | 必须在**项目根目录**执行命令（`F:\WorkSpace\Newstart`），不是在 `scripts/` 里 |
| `ModuleNotFoundError: No module named 'langchain'` | 虚拟环境没激活，或依赖没装。用 `.venv\Scripts\python.exe` 的完整路径执行 |
| 前端显示「❌ 无法连接后端」 | 后端没启动，或端口不是 8000。检查终端 1 是否在跑 |
| `/query` 返回 503 | 知识库为空。先跑 `ingest_cli.py` 入库 |
| 上传 PDF 报「提取不到任何文本」 | 扫描版 PDF（图片型），本系统不含 OCR。先用 `ocrmypdf` 转成文本型 |
| 换 Embedding 后报维度不匹配 | 删 `data/chroma` 目录重建，或 `--reset` 重新入库 |
| Streamlit 页面空白/报 YAML 错 | 通常是依赖冲突，重装：`pip install -r requirements.txt --force-reinstall` |
| 端口被占用 | `--port 8001` 换端口，前端侧边栏也要改后端地址 |
| 配了 API 还是报 500 / `APIConnectionError` | 先跑 `.venv\Scripts\python.exe scripts/doctor.py` 做五层体检（代理/DNS/TCP/TLS/模型名）。**最常见元凶是进程里的 `HTTP_PROXY` 被 httpx 自动读取** |

更多报错见 `docs/05-常见问题与排错.md`。
